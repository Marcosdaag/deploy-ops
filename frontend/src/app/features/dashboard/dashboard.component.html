ARQUITECTURA

Ingeniería de Producción

Arquitectura de observabilidad construida con Java 21, Spring Boot y Supabase PostgreSQL.

Seguridad

Anti-SSRF & DNS Guard

Bloqueo estricto de loopbacks (127.0.0.1), redes locales RFC1918 y servicios de metadatos cloud.

Concurrencia

Virtual Threads de Java 21

Pings paralelos ultra-ligeros con memoria constante mediante Executors.newVirtualThreadPerTaskExecutor().

Algoritmos

SLA en Tiempo O(1)

Cálculo de disponibilidad de 30 días sin consultas N+1 en PostgreSQL sobre Supabase.

Protección

Sliding Window Rate Limiter

Filtro de seguridad que previene abuso en rutas de autenticación y pings con respuestas 429.
