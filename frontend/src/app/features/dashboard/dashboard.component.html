ARQUITECTURA

Fundamentos Técnicos & Resiliencia

Diseñado bajo estándares de ingeniería de confiabilidad de sitios (SRE) con Java 21 y Angular 20.

Seguridad de Red

Protección Anti-SSRF Estricta

UrlSecurityValidator resuelve el host por DNS y bloquea loopbacks (127.0.0.1), rangos RFC1918 privados, metadatos cloud (169.254.169.254) y puertos no HTTP (SSH, bases de datos).

Concurrencia

Virtual Threads de Java 21

Cada ping se despacha en un Virtual Thread no bloqueante mediante Executors.newVirtualThreadPerTaskExecutor(), garantizando memoria plana sin pool exhaustivo de hilos OS.

Algoritmos SRE

Cálculo de SLA en Tiempo O(1)

MetricsService procesa incidentes solapados en ventana móvil de 30 días calculando el downtime con precisión de segundos, indexado en PostgreSQL en Supabase.

Protección API

Sliding Window Rate Limiter

Un filtro HTTP independiente estrangula peticiones de login, registro y pings manuales por IP retornando cabeceras 429 Too Many Requests y Retry-After.
