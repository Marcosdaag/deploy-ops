04 — Ingeniería de Producción

Construido con rigor arquitectónico de punta a punta.

Seguridad de Red · SSRF Shield

Validación DNS e inspección de IPs privadas

Antes de registrar o contactar cualquier URL, UrlSecurityValidator resuelve el host mediante InetAddress y bloquea esquemas no HTTP/S, loopback (127.0.0.1 / localhost), redes locales (10.x, 192.168.x) e instancias de metadatos cloud (169.254.169.254).

Rendimiento · Memoria Constante

Sondeo ligero sin descarga de cuerpo

HttpMonitorService ejecuta peticiones descartando el payload HTML (Void.class) con timeouts estrictos (3s conexión, 5s lectura) y mide latencia con reloj monotónico (System.nanoTime()).

Precisión Matemática · SLA 30D

Cálculo de disponibilidad sin consultas N+1

MetricsService recupera en una única consulta batch todos los incidentes solapados en la ventana móvil de 30 días, recortando bordes temporales al segundo exacto.

Infraestructura · CI/CD & Cloud

Pipeline con GitHub Actions, Docker Multi-Stage y Supabase

Cada push ejecuta pruebas unitarias y de integración sobre un contenedor efímero PostgreSQL 16 en GitHub Actions antes de desplegar la imagen eclipse-temurin:21-jre-alpine en Render conectada a Supabase.
